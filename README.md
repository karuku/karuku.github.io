# Robert Karuku Portfolio Landing Page

Lightweight static landing page for Robert Karuku, linking to the detailed portfolio at <https://karuku.github.io/portfolio/>.

## Local preview

Open `index.html` directly in a browser, or serve this directory with any static HTTP server. The page has no build step, runtime JavaScript, or third-party dependencies.

## Content updates

- Edit the page structure and search metadata in `index.html`.
- Keep presentation rules in `assets/css/landing.css`.
- Keep project summaries aligned with the source repositories under `https://github.com/karuku/portfolio`.
- Update `sitemap.xml` if the canonical page URL changes.

## Deployment

Deploy the repository root with GitHub Pages. The canonical landing-page URL is `https://karuku.github.io/`; the detailed project portfolio remains at `https://karuku.github.io/portfolio/`.

## Quality checks

Check the page at desktop and mobile widths, test keyboard-only navigation and reduced-motion preferences, and validate the metadata and links before publishing. No package installation is required.
